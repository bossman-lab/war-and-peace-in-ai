# 《AI时代的战争与和平》

AI不是互联网的延续，而是一场物理基础设施争夺战。权力分配发生在芯片、能源、矿物、数据、人才五个瓶颈处，而非算法榜单上。

全书共 **四部 + 终章 + 附录，11章**，以地理政治经济学的视角剖析AI时代的全球权力重构。
